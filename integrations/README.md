# integrations

Hier installiert der Hub die Komponenten, die **du selbst** von den offiziellen Projektseiten heruntergeladen hast
(Hub → Komponenten → „Aus Datei installieren …“). Dieses Verzeichnis ist im Repository leer. Der Hub lädt nichts herunter.

- `dolphin/`, `cemu/`, `switch/` (Eden), `melonds/`, `azahar/`: Emulatoren, jeweils portabel
- `switch/user/keys/`: deine eigenen Keys (`prod.keys`) für Eden
- `switch/mods-store/`: deaktivierte Mods (der Hub aktiviert sie passend zur gewählten Edition)
- `wiicompiled/`, `wheelwizard/`, `padforge/`: optionale Tools
- `_downloads/`: Ablage für selbst heruntergeladene Pakete; der Hub bietet sie zur Installation an
